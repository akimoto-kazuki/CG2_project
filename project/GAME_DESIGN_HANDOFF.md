## ゲーム概要

個人制作のゲームです。ゲームプレイは「作業パート」と「戦闘パート」を繰り返します。

- 作業パートでは、木・石・鉱石などの素材を集め、素材を使って武器や道具を作ります。
- 戦闘パートでは、作った武器を使って敵と戦います。
- 戦闘をクリアすると、次の作業パートで新しい素材を集められるなど、プレイヤーが強くなります。
- 進行に応じて敵も強くなり、最後にボスを倒すとゲームクリアです。

基本の流れ：

**素材を集める → 武器を作る／選ぶ → 敵と戦う → 新しい素材や強化を得る → 次の戦闘へ → ボスを倒してクリア**

## 制作方針

作業パートを単なる素材集めにしないことを重視します。採掘した素材が武器作成や戦闘に結びつき、「何を集めるか」「何を作るか」の選択が戦闘結果に影響する形を目指します。

- 素材数や作業時間を増やすだけで遊びを引き延ばさない。
- まず少数の素材・武器・敵で、作業から戦闘までのつながりを完成させる。
- 最初は選択肢ごとの違いが分かる、少数の武器でよい。
- 機能を増やす前に、作業の選択が戦闘で役立ったと感じられるかを確かめる。
- 学校の要素別コンテストに取り組みながら、最終的にゲーム全体のループを完成させる。

## 合意した制作チャート

次の順に、小さく動くものを完成させます。

1. **作業パートの目標を決める**  
   次の戦闘に向けて何を準備するのかをプレイヤーに分かるようにします。例：木材か鉱石を集めて次の武器を用意する。
2. **素材から武器を1つ作る**  
   素材を消費して武器を作れるようにし、武器の性能差を戦闘で感じられるようにします。
3. **敵を倒せる戦闘を作る**  
   プレイヤーの攻撃、敵のHP、撃破判定を作ります。
4. **戦闘結果で次へ進める**  
   勝利したら次の作業パートへ進み、プレイヤーのHPが尽きたらゲームオーバーへ進みます。
5. **強化と敵の強化を一度つなぐ**  
   戦闘後に新しい素材か強い武器を解放し、次の敵を少し手強くします。
6. **ボスを倒してクリアする**  
   作業・通常戦闘・強化を経てボスを倒し、ゲームクリア画面へ進みます。

### 最低限の完成ライン

最初から大量の素材・武器・敵を作らず、次の一周を完成させることを全体の最低ラインとします。

**作業パート1回 → 武器作成 → 通常戦闘1回 → 1段階の強化 → ボス戦 → ゲームクリア**

この一周を通して、集めた素材の選択が武器に反映され、その武器が戦闘で役立つことを確認できたら、ゲームの基本ループとして「最低限ここまでできたらよし」とします。
