# 武器・モデル・モーション制作 引き継ぎ

武器担当のコード作業チャットへ渡す仕様と進行メモです。ゲーム全体は [GAME_DESIGN_HANDOFF.md](GAME_DESIGN_HANDOFF.md) を参照し、コード作業前に現状を確認してください。

## ゲーム概要

素材を採掘して武器を作り、その武器で敵やボスと戦うアクションゲームです。現在は木の剣・鉱石の剣を作って戦う進行があります。

## 今回の確定希望

- 既存の剣に加えて、**ハンマーとやり（槍）**を追加する。
- 剣・ハンマー・やりの**簡易モデル**を用意する。
- 武器ごとに動きが分かる攻撃モーションを追加する。
  - 剣：振る。
  - ハンマー：頭上から振り下ろす。
  - やり：前方へ突き刺す。
- 攻撃モーションと攻撃判定のタイミングを合わせる。ボタンを押した瞬間に常にダメージが出るだけの動作にしない。
- 既存の素材・作成・戦闘進行を壊さず、最初に必要素材や数値の案を提示する。

具体的な攻撃力、攻撃速度、射程、レシピ、武器の選択・装備方法は未確定です。コード変更前の実現方法確認で、少数の分かりやすい差が出る案を提示してください。剣より強い武器を順に足すだけでなく、武器ごとに役割を持たせます。例：剣は標準、ハンマーは遅いが強く地面攻撃がある、やりは長い射程を持つ。

## 実装前の確認（最初はコードを変更しない）

現在の `GamePlayScene` の武器作成・装備・攻撃処理、プレイヤー／敵のモデルとアニメーションの読み込み、`Object3d` と `AnimationClass` の機能、使用可能な素材・アセット形式を確認してください。そのうえで以下を説明してください。

- 既存剣と新しい武器をどう共存させるか。作成・所持・装備・HUDへの影響。
- 各武器にどの程度異なる攻撃判定・威力・速度を持たせられるか。
- 簡易モデルの作成・読み込み方法と、プレイヤーの手に保持させる方法。
- 既存アニメーション機能で各モーションを実現できるか。無ければ、ワールド変換を動かす簡易アニメーションなど代案と制約。
- 攻撃モーション中のどのタイミングで命中判定を行うか。
- 追加・変更が必要なファイル、作業順、既存コードへの影響、難しい点。
- クラス分割を先に行う場合の依存関係と、同じファイルを複数チャットが同時に編集するリスク。

**この確認段階ではコード・モデル・アニメーションを変更しないでください。** 実装案と作業範囲を説明し、ユーザーが依頼した後に着手してください。仕様が複数考えられる場合は、第一案と代案を並べてください。

## 作業順の目安

1. 既存の剣を含む武器データ・作成・装備処理の設計を確認する。
2. ハンマーとやりの役割、レシピ、入力・装備方法を決める。
3. 簡易モデルと装備表示を追加する。
4. 剣の振り、ハンマーの振り下ろし、やりの突きを加える。
5. 攻撃判定を各動作の適切なタイミングに合わせる。
6. ビルドと実機操作で、見た目・当たり判定・武器差を確認する。

ハンマーの土飛散エフェクトは、この武器作業が完了し、振り下ろし・地面判定が動作確認できた後、[EFFECTS_HANDOFF.md](EFFECTS_HANDOFF.md) の担当チャットで進めます。先行実装しないでください。

## 主な関連ファイル

- `GamePlayScene.cpp` / `GamePlayScene.h`：武器の種類、作成、攻撃、ゲーム進行。
- `Object3d.cpp` / `Object3d.h`：モデル表示・変換・アニメーション機能。
- `AnimationClass.cpp` / `AnimationClass.h`：既存アニメーション機能。
- `ModelManager.cpp` / `ModelManager.h`：モデル読み込み。
- `resources/`：モデル・アニメーション素材。

## 完成目安

- 剣・ハンマー・やりを作成／装備して戦闘に使える。
- 3種類それぞれのモデルが見分けられる。
- 攻撃モーションが武器ごとに異なり、見た目の動作と攻撃判定の発生が一致する。
- ハンマーは振り下ろしの接地位置をエフェクト担当へ伝えられる。
- 既存の素材ループ、敵、ボス、勝敗・クリア遷移が維持されている。

## 作業後の報告

変更ファイル、武器ごとの確定仕様、モデル・モーションの方式、ビルド／実機確認の内容、残った制約を報告してください。未確認項目は明示してください。
